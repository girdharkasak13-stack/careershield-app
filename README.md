# CareerShield — Local Setup (VS Code)

## Requirements
- Node.js installed (v18 or higher) — download from https://nodejs.org

## Steps
1. Open this folder in VS Code (File > Open Folder)
2. Open the built-in Terminal (Terminal > New Terminal)
3. Run:
   npm install
4. Then run:
   npm run dev
5. Terminal mein ek link milega (usually http://localhost:5173) — Ctrl+Click karke browser mein khol lo.

That's it — the app will be running live from VS Code.
